BẢN THỬ TRANG PHỤC HOÀNG GIA – CẤP 1, 2, 3

1. Máy tính: mở game-hoang-gia-v2.html bằng Chrome/Edge để thử không cần cài npm.
2. Điện thoại: đưa NỘI DUNG thư mục web lên hosting HTTPS rồi mở link bằng Safari.
   Không dùng cửa sổ xem trước HTML trong ứng dụng Tệp để đánh giá game.
3. Trang phục thử được bật sẵn và miễn phí. Bấm thanh vàng trên cùng để so sánh.
4. Bấm chơi; cấp 1–3 dùng ảnh thân Hoàng gia, mắt/miệng vẫn thay đổi theo trạng thái.
5. Cấp 4–12 giữ hình cũ. Các bộ Sakura và Cyber chưa được thay trong bản thử này.
6. Mục đích: kiểm tra hình nhỏ, rơi, xoay, biểu cảm và độ mượt trên thiết bị thật.
7. Dữ liệu không đồng bộ giữa file HTML và website. Nên thử ở địa chỉ mới để không
   ảnh hưởng dữ liệu của bản game đang dùng. Không bấm xóa dữ liệu bản chính.

Mã nguồn: thư mục source. Chạy npm install, npm run dev hoặc npm run build.
Tài nguyên ảnh: tạo bằng công cụ tạo ảnh từ mẫu Hoàng gia đã duyệt;
yêu cầu chung: vật y tế, nền alpha, kem–đỏ đô–vàng, không vẽ mắt/miệng/má.
Chi tiết: viên thuốc áo choàng + vương miện; băng cá nhân hai đầu đỏ đô/vàng,
miếng gạc kem trống giữa; băng cuộn hồng bọc nhung đỏ, panel mặt kem trống.

V2: thu ảnh qua nhiều nấc; làm mượt chất lượng cao; Canvas chính vẽ 2–3x; ô NEXT theo độ phân giải màn hình và cập nhật khi đổi hình.
Nhận biết bản mới: thanh vàng ghi ẢNH HOÀNG GIA V2.
